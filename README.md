## 👋 Sobre mim

- ☕ Desenvolvedor **Java Júnior** com foco em **back-end** (Java 21, JDBC, SQL/MySQL, POO, DAO), apaixonado por criar sistemas de gestão que resolvem problemas reais
- 🏢 Atualmente na **Casa Pio**
- 📍 Fortaleza - Ceará, Brasil
- 🧩 Já construí sistemas para **PDV, estoque, ordem de serviço, clínica, farmácia, lanchonete e padaria**
- 🗄️ Gosto de organizar o código em camadas, com o **padrão DAO** e persistência em **MySQL**

## 🔨 No que estou trabalhando

- 🧾 **[sistema-vendas-estoque-java](https://github.com/KlleberJose/sistema-vendas-estoque-java)**: PDV desktop com controle de estoque (Java 21 + Swing + JDBC + MySQL)
- 🔧 **[infox-ordem-servico-java](https://github.com/KlleberJose/infox-ordem-servico-java)**: sistema desktop de ordens de serviço com a mesma stack
